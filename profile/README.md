# Curumim Games

Estúdio independente. Jogos pequenos hoje, maiores amanhã.

Fazemos jogos curtos para jogar no navegador e no celular, e cada um deixa a base para o próximo.

## Agora

O primeiro jogo está em desenvolvimento: um puzzle de peças caindo, com regra própria e níveis.

## Sobre o nome

Curumim é "criança" em tupi. É por onde tudo começa.
